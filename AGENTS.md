# Agent Instructions

Before making project decisions or code changes, read:

1. `docs/project_memory.md`
2. `docs/decisions/README.md`
3. Relevant decision records in `docs/decisions/`

Keep these documents current. When a session makes a durable project choice,
update `docs/project_memory.md` and add or amend a decision record before
committing. Do not rely on chat history as the only source of project intent.

The local dataset under `data/` is intentionally ignored by Git. Do not commit
clinical data, virtual environments, caches, generated models, or generated
outputs unless the user explicitly changes that policy.
