# Decision Log

This folder records durable project decisions. Each decision should explain the
choice, why it was made, and what it means for future work.

When a future session makes a meaningful project choice:

1. Update `docs/project_memory.md`.
2. Add a new decision record or amend the relevant existing one.
3. Keep the decision tied to evidence from the data, literature, or project
   constraints.
